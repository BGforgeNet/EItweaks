EItweaks is a mod for Evil Islands: Curse of the Lost Soul. It includes multiple fixes and various tweaks, QoL and a few balance changes. It bundles [EIStarter-UM](docs/starter.md), [eix](docs/eix.md) (EI starter's add-on reimplemented, with SpellAddon built in), and Universal Mod's runtime with D7VK for Wine. Installation needs no internet connection.

## Tweaks

The tweaks are mostly to make things more consistent within the game, add some flavour, improve QoL. Also close obvious exploits, but give PC a chance against previously impossible enemies, with [Hardcore](https://pihwiki.bgforge.net/Evil_Islands:_Curse_of_the_Lost_Soul) play style in mind.

- [Gameplay](docs/gameplay.md): faster human walking and running, stamina, killable golems and dragons, no XP exploits, and mercenaries travelling with the hero (starter version).
- [Speedup](docs/speedup.md): no intro movies, help screens off by default.
- [Items](docs/items.md): dragon hide, a stronger Green Dragon Horn, more goods on Gipath, blue harpy heads.
- [Regeneration](docs/regeneration.md): much slower regeneration, none for undead, golems and other unliving monsters.
- [Resistances](docs/resistances.md): consistent protections for armor materials and monsters.

## Installation

The game must be at version 1.06. The GOG releases are ready as they are. If you have an older version, grab [1.06](https://allods.gipat.ru/index.php?p=filesei#patch-1-06) first.

Download the installer, `eitweaks-<version>.exe`, from the latest [release](https://github.com/BGforgeNet/EItweaks/releases/latest) and run it.
