EItweaks is a mod for Evil Islands: Curse of the Lost Soul. It includes multiple fixes and various tweaks, QoL and a few balance changes.

EItweaks utilizes [eix](docs/eix.md) and [EIStarter-UM](docs/starter.md) to provide engine fixes and tweaks such as widescreen and HQ music support, AutoPause, dynamic run speed, and more.

## Tweaks

The tweaks are mostly to make things more consistent within the game, add some flavour, improve QoL. Also close obvious exploits, but give PC a chance against previously impossible enemies, with [Hardcore](https://pihwiki.bgforge.net/Evil_Islands:_Curse_of_the_Lost_Soul) play style in mind.

- [Gameplay](docs/gameplay.md): faster walking and running, stamina rebalance, killable golems and dragons, no XP exploits, and mercenaries travelling with the hero.
- [Speedup](docs/speedup.md): no intro movies, help screens off by default.
- [Items](docs/items.md): dragon hide, a stronger Green Dragon Horn, more goods on Gipath.
- [Regeneration](docs/regeneration.md): rebalanced (much slower) regeneration)
- [Resistances](docs/resistances.md): consistent protections for armor materials and monsters.

## Installation

The game must be at version 1.06. The GOG releases are ready as they are. If you have an older version, grab [1.06](https://allods.gipat.ru/index.php?p=filesei#patch-1-06) first.

Download the installer, `eitweaks-<version>.exe`, from the latest [release](https://github.com/BGforgeNet/EItweaks/releases/latest) and run it.

### Recommended mods

- [Evil Islands HQ music](https://github.com/BGforgeNet/Evil_Islands_HQ_music): lossless FLAC music for most tracks, and several tracks the game has but never plays. The FLAC tracks play in the starter version of EItweaks.
