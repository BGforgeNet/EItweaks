## Standalone

Installed directly into game directory. Use if you don't like the [launcher](starter.md) for some reason, or are playing Cursed Lands. The files it replaces are backed up into `eitweaks-backup` and put back when EItweaks is uninstalled.

It brings EItweaks' data and text changes only. Differences:

- Disables only the camp and map help screens: turn off Options > Windows > Show tutorial for the rest.
- Lacks 1.07's missing face texture fix.
- No [eix](eix.md), so none of its fixes and options, and none of the fixes and changes that use its SpellAddon: running stamina, item action runes in wands, and the others marked in [fixes](fixes.md).
- No D7VK.
