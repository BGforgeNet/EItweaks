## SpellAddon

[SpellAddon](https://evilislandsaddon.forumotion.com/) is a set of changes to the game. EItweaks includes version 20.6 and uses one of them: running stamina.

SpellAddon includes many more customization options. Should you want to use them, edit `SPELLADDON.INI` in the EItweaks' folder (starter version) or the game folder (standalone version).
