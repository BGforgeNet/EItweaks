## SpellAddon

[SpellAddon](https://evilislandsaddon.forumotion.com/) is a set of changes to the game. EItweaks includes version 20.6 and uses three of them: running stamina, no item action runes in wands, and a fix for a crash when certain objects come into view (`ultrafixes`).

SpellAddon includes many more customization options. Should you want to use them, edit `SPELLADDON.INI` in EItweaks' folder, `Mods\eitweaks` in starter's folder (starter version), or the game folder (standalone version).
