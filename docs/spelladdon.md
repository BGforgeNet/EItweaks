## SpellAddon

[SpellAddon](https://evilislandsaddon.forumotion.com/) is a set of changes to the game. EItweaks includes version 20.6 and uses two of them: running stamina, and no item action runes in wands.

SpellAddon includes many more customization options. Should you want to use them, edit `SPELLADDON.INI` in EItweaks' folder, `Mods\eitweaks` in starter's folder (starter version), or the game folder (standalone version).
