## SpellAddon

[SpellAddon](https://evilislandsaddon.forumotion.com/) is a set of changes to the game. EItweaks includes version 20.6 and uses some of them: running stamina, no item action runes in wands, a fix for a crash when certain objects come into view (`ultrafixes`), gradual dawn and night vision in caves (`nightpowervisionpatch`, `nightvisionincaves`), and the Middle Mountains map choice (`removefrozenvar`). See [fixes](fixes.md).

SpellAddon includes many more customization options. Should you want to use them, edit `SPELLADDON.INI` in EItweaks' folder, `mods\eitweaks` in EIStarter-UM's folder (starter version), or the game folder (standalone version).
